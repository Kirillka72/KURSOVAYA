Wish List App

Веб-приложение "Wish List" — это простой менеджер желаний (задач), позволяющий добавлять, редактировать, удалять и отслеживать список целей с использованием фильтрации, сортировки и локального хранилища браузера.

---

Функционал

Основные возможности:
- Добавление нового желания
- Редактирование существующих элементов
- Удаление записей
- Отметка статуса:
  - Запланировано
  - В процессе
  - Выполнено
- Приоритеты:
  - Low / Medium / High

Дополнительно:
- Поиск по названию и описанию
- Фильтрация по статусу
- Сортировка:
  - по дате
  - по приоритету
  - по названию
- Хранение данных в `localStorage`
- Автоматическое сохранение состояния
